# Code of conduct

pencilmark follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):
be kind and constructive, and assume good faith. It applies in the issues, pull requests, discussions and anywhere you
represent the project.

## Reporting

Report behaviour that breaks it privately, through the repository's private reporting form: the **Security** tab,
**Report a vulnerability** ([direct link](https://github.com/silly-puppyy/pencilmark/security/advisories/new)). Start
the title with "Conduct:". Only the maintainers see it. Reports are handled as the Contributor Covenant's enforcement
guidelines describe, and the reporter's identity is kept private.
