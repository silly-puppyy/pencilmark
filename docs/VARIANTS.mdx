# Variants

pencilmark grades any puzzle written in the [puzzle format](FORMAT.md); a variant needs no name to be solved. The
names on this page are what `describe()` and `meta.type` call a puzzle when its rules match a known pattern
([Variant names](NAMING.md) gives the exact rules). Rule families such as killer cages, thermometers and Kropki dots
have their own pages under [Rule families](/rule-families/).

## Placement variants

A placement variant adds fixed regions to one grid. pencilmark recognises it when every region it adds is present, on
any board size where it is defined.

</Cards>

## Multi-grid layouts

A multi-grid board is written as one `box_grid` per 9×9 grid ([Houses and regions](rules/houses-and-regions.mdx)).
When the grids' top-left cells match a named layout, the puzzle takes its name: "Samurai Sudoku", "Killer Twodoku". In
the drawings, overlapping grids have different tints, so the shared boxes show as a blend. Another arrangement is a
"Multi-Grid Sudoku" and is graded the same way.
