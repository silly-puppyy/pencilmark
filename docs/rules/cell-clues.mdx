# Cell clues

This page covers clues on single cells: odd, even, low, high, set and exclude (6.12).

## 6.12 `cell` (cell clues)

```json
{"type": "cell", "kind": "odd", "cells": ["r1c1", "r5c5"]}
{"type": "cell", "kind": "set", "values": [1, 2, 3], "cells": ["r2c2"]}
{"type": "cell", "kind": "high", "split": 5, "cells": ["r3c3"]}
```

<div className="pm-kinds">

| `kind` | Fields | Each listed cell holds | Drawing |
|---|---|---|---|
| `odd` / `even` | – | an odd / even digit | <Swatch name="cell-odd" /> <Swatch name="cell-even" /> |

| `exclude` | `values` | none of `values` |  |

</div>
