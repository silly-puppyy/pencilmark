# Draw a puzzle

The repository has a reference renderer, `tools/render_svg.py`, that draws a `pencilmark-puzzle` file as SVG in the
default style of [Drawing and style](../../library/drawing-style.md). It is not part of the installed package; run it from a clone.

```
python tools/render_svg.py docs/examples/mini-thermo-kropki.json mini.svg
python tools/render_svg.py docs/examples/mini-thermo-kropki.json mini-dark.svg --dark
```

This is the puzzle from [Write a variant puzzle file](variant-file.mdx). `--cell N` sets the size of a
cell in pixels (48 by default).

From Python, with the `tools` folder on the path:

```python
import json, render_svg

doc = json.load(open("docs/examples/mini-thermo-kropki.json"))
svg = render_svg.render(doc, dark=False, cell=48)
```

## A position of a solve, with its colours

A card's `trace` ([Grade card](../../formats/grade-card.md) section 6) holds the board after each step, with the colours
an expert would have painted. `--card` and `--position` draw one position: its placed digits in the solver's ink and
its colours over the cells, under the lines, cages and digits. A cell in two colours is split along a tilted diagonal,
in three into thirds, and so on, as SudokuPad draws several colours in one cell:

```
pencilmark rate puzzle.json --json --fields band,trace > card.json
python tools/render_svg.py puzzle.json step38.svg --card card.json --position 38
```

From Python, `render_svg.render(doc, colours={"r2c5": ["green", "yellow"]}, placed={"r1c2": 8})` draws any colours
you choose; [Palette](../../library/palette.md#annotation-colours) lists the colour names and their shades.

The small drawings on the [rule pages](../../formats/puzzle-format.md#6-rule-families) come from this renderer. It always uses the default style, with
line colours most puzzle setters use; [Drawing and style](../../library/drawing-style.md) lists every size and colour, and
`docs/palette.json` holds them in one file for other renderers.
