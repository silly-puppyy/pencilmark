# Generator examples

One request per feature of the [generator spec](../../formats/generator-spec.md), each with the puzzle it produced and its card. The seed fixes the result: the same request on the same version gives the same puzzle. Written by `tools/gen_generator_examples.py`.

## A Hard classic with an X-Wing

Shows a band target, a required technique (strict), 180° symmetry.

```json
{"format": "sudoku-spec",
 "format_version": 1,
 "board": {"rows": 9, "cols": 9},
 "digits": 9,
 "rules": [{"type": "box_grid", "origin": "r1c1", "box": [3, 3]}],
 "symmetry": [{"kind": "rot180", "of": "givens"}],
 "where": {"band": "Hard", "contains": {"codes": ["XWG"], "strict": true}},
 "limits": {"time": 180, "seed": 1}}
```

<Swatch name="generated-classic-hard-xwing" />

**Hard**, difficulty 6.1, about 12.0 min. Contains: Hidden Single, Pointing / Box-Line Reduction, Naked Pair, Hidden Pair, X-Wing.
